# T8 — Unsloth QLoRA fine-tuning dependencies (see scripts/ml/README.md).
#
# Two-step install — a single `pip install -r` can't do this, because pip
# resolves every listed package's declared dependencies, and Unsloth declares
# xformers (no Windows wheel exists for any xformers release built against
# torch 2.5.1) and diffusers (unused; only its image-model paths need it).
# So Unsloth is deliberately left out of this file and installed separately,
# with --no-deps, after everything below:
#
#     python -m venv scripts/ml/.venv
#     scripts/ml/.venv/Scripts/python -m pip install -r scripts/ml/requirements.txt        # Windows
#     scripts/ml/.venv/Scripts/python -m pip install --no-deps unsloth==2026.8.18 unsloth_zoo==2026.8.12
#
#     scripts/ml/.venv/bin/python -m pip install -r scripts/ml/requirements.txt             # Linux
#     scripts/ml/.venv/bin/python -m pip install --no-deps unsloth==2026.8.18 unsloth_zoo==2026.8.12
#
# Install into an ISOLATED venv (not --system-site-packages): transformers
# imports TensorFlow when it can see one, and an unrelated global TF/protobuf
# pair is enough to break `import trl` outright.
#
# torch is pinned to the +cu121 local build, which only exists on the PyTorch
# index below — so the resolve is deterministic on both Windows and Linux
# rather than silently picking up PyPI's cu124 wheel.

# (10-step smoke test: loss 1.87 -> 1.28, peak VRAM 2.83GB). On Linux
# (T10/T11's Oracle box) xformers installs cleanly and can be added back for
# a modest speed-up — it is not required for correctness.
#
